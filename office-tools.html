MDS ORBIT · OFFICE & FILE WORKSPACE

Work with files.
One simple place.

Open and process common Office files, convert spreadsheets, extract document text, recognize text in images and manage ZIP archives.

Privacy: Processing happens in your browser using open-source libraries loaded from public CDNs. Files are not sent to an MDS ORBIT server. First use requires internet. Complex page layout conversion is not supported in every format; check the output before using it.
