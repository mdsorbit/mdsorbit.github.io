PROMPT WRITING NOTES

How to adapt a visual prompt

A prompt works best when it describes the subject, setting, composition, lighting, visual style and output format. Treat prompt examples as starting points and adjust them for the image generator you use.

Build a clearer prompt

  • Subject: describe the main person, object or scene.
  • Composition: specify close-up, wide shot, viewpoint and placement.
  • Environment: describe the location, background and time of day.
  • Lighting and style: mention the mood, light direction and visual treatment.
  • Output: state aspect ratio, intended use and any elements to avoid.

Different image models interpret wording differently. Review the model provider's content rules and usage rights before publishing generated work. Prompt examples are provided for inspiration, not guaranteed results.
